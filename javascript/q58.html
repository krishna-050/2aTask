🌐 What is HTML?+

HTML (HyperText Markup Language) is the standard language for creating web pages. It describes the structure of a web page using elements and tags.

🎨 What is CSS?+

CSS (Cascading Style Sheets) is used to style and layout web pages. It controls colors, fonts, spacing, and responsive design.

⚡ What is JavaScript?+

JavaScript is a programming language that adds interactivity to web pages. It runs in the browser and can manipulate the DOM dynamically.

🚀 What is a Framework?+

A framework is a pre-built structure that provides tools and conventions to speed up development. Examples include React, Vue, and Angular.
