🌐 What is HTML?+
HTML is the standard language for creating web pages using elements and tags.
🎨 What is CSS?+
CSS is used to style web pages — colors, fonts, spacing, and layout.
⚡ What is JavaScript?+
JavaScript adds interactivity to web pages and runs in the browser.
🚀 What is a Framework?+
A framework is a pre-built structure to speed up development. Examples: React, Vue.
